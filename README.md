# Bereket Abebe: portfolio

Source of https://beki-hck.github.io. Plain HTML, CSS and JavaScript: no framework, no build step, no tracking.

- `index.html`, `styles.css`, `main.js`: the page, the look and the motion.
- `ask-data.js`: the answers behind the "Ask about my work" box (a keyword search that runs in the browser, no AI API).
- `video/`: narrated walkthrough of Baltina, recorded with made-up demo data.
